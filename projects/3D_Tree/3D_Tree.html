Description

Me messing around with Meshy AI to generate a free 3D tree model, then downscaling and optimizing it so it loads smoothly in the browser, on both desktop and mobile.

Background

This is a small, working slice of a much bigger project that's still in progress. The tree model was generated with Meshy AI. The original file weighed 21MB; I downscaled it to 433KB, and the difference in detail is barely noticeable.

The background is a flat 2D image generated with ChatGPT. I upscaled it with Upscayl to add detail, then scaled it back down to its current size. AI upscalers tend to leave small artifacts: over-sharpened edges, repeating textures, and odd detail in flat areas like grass and flowers. Shrinking a larger image averages several pixels into each final pixel, which smooths those artifacts out. Rendering big and scaling down (supersampling) gives a cleaner result than generating at the target size directly.

The clouds are all the same 2D WebP image. Each copy gets its own opacity and horizontal stretch, so they look like many different clouds even though there's only one.

To make this simple version feel more alive, I added a cinematic tour: the camera pans around the scene on its own, an idea borrowed from my favorite childhood game, Heroes of Might and Magic V.

There's more to come. I'm turning this into a community project where every visitor can leave something behind before they go, so stay tuned.
