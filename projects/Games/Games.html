Games
Description

A small collection of classic games recreated for the browser. Each one is a self-contained project - pick one below to play.

Bejeweled X

A web revival of the classic match-3 game Bejeweled 2, using the original assets and re-implemented in vanilla JavaScript.

Flappy Bird

A web revival of the classic Flappy Bird, using the original 2014 assets and re-implemented in vanilla JavaScript.

Achilles

The 2008 Flash brawler Achilles, running unmodified through the Ruffle emulator with touch controls added.
